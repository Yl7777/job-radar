# 推送渠道配置（模板）

> 复制本文件为 `profile/push-config.md` 后，按实际情况填写。
> 定时任务读取本文件决定往哪推。未填写的渠道自动跳过，不会导致任务失败。
> **本文件含 webhook 凭证，已加入 .gitignore，切勿提交到 Git 仓库。**

## 渠道一：微信（主推，推荐）

- 状态：**已启用**
- 连接方式：微信助理集成（Claw 通道，在 WorkBuddy 设置里扫码连接）
- 内容：精简日报（摘要 + 🟢 档详情 + 🟡 列表，控制手机可读长度）
- 说明：每日自动化跑完后，通过微信 Claw 通道推送到你的手机。这是主要推送渠道。

## 渠道二：邮件（Agent Mail，可选备份）

- 状态：**待配置**
- 收件地址：`（填你的邮箱）`
- 发送方式：Agent Mail 连接器（在 WorkBuddy 里连接）
- 标题：`[岗位雷达] M/D 新增 N 个岗位`
- 内容：完整日报（🟢 详情 + 🟡 列表）

## 渠道三：群机器人 Webhook（企业微信 / 飞书，可选）

- 状态：**待配置**
- 类型：`企业微信` 或 `飞书`
- Webhook 地址：`（填 webhook URL）`
- 内容：精简版（摘要 + 🟢 档，20 行内）

### 怎么拿 webhook

**企业微信**：群右上角「···」→ 添加群机器人 → 新建 → 复制形如
`https://qyapi.weixin.qq.com/cgi-bin/webhook/send?key=xxxxxxxx` 的地址。

**飞书**：群设置 → 群机器人 → 自定义机器人 → 复制形如
`https://open.feishu.cn/open-apis/bot/v2/hook/xxxxxxxx` 的地址
（若开启签名校验，把密钥一并填到下方）。

> 安全提示：webhook 等同往该群发消息的凭证，只写本地此文件，不提交 Git。

## 渠道四：本地日报（默认开启，无需配置）

- 状态：**已启用**
- 路径：`job-radar/reports/YYYY-MM-DD.html`

## 推送时间

默认 08:00，由 WorkBuddy 自动化的任务时间控制。改时间：在自动化设置里改任务时间即可，本文件只作记录。
