# 公司分类规范（Company Classification）

本规范用于给检索到的岗位标注 `company_tag`（公司类型），让报告不仅能按匹配度分组，
还能按「公司画像」筛选（例如「只看 AI 独角兽」「只看大厂」）。

## 标签枚举

| 标签 | 含义 | 典型代表 |
|---|---|---|
| `大厂互联网` | 一线互联网平台型公司 | 字节、腾讯、阿里、美团、京东、拼多多、百度、网易、快手、小红书、B站 |
| `AI独角兽` | 以大模型 / 生成式 AI 为核心的人工智能公司 | 智谱、MiniMax、Kimi、百川、零一万物、阶跃、生数 Vidu、爱诗 PixVerse、商汤、旷视 |
| `AI研究/院校` | 高校实验室、研究院、科研机构 | 各高校 AI 实验室、之江实验室、鹏城实验室 |
| `科技出海` | 主要业务在海外 / 全球化的中国科技公司 | SHEIN、字节出海、赤子城、易点天下 |
| `中厂/成长型` | 细分领域头部但规模小于大厂 | 小红书(部分归类)、B站、SHEIN、米哈游、莉莉丝 |
| `创业公司` | 早期初创团队（A 轮及以前为主） | 各类 AIGC 创业团队 |
| `国企/央企` | 国有企事业单位 | 运营商、银行科技子公司、中移、国网 |
| `外企` | 外资企业中国区 | 微软、谷歌、苹果、亚马逊、Meta 等中国岗位 |
| `其他` | 无法归入以上、或传统行业 | 制造业、金融、教育等 |

## 标注规则（给 AI 执行检索 / 生成 JSON 时遵循）

1. 每个岗位在 `jobs_raw.json` 里带一个 `company_tag` 字段，取值为上面枚举之一。
2. 优先用最具体的标签：既是大厂又是 AI 业务的，**优先标 `AI独角兽` 还是 `大厂互联网`？**
   - 若公司主体就是 AI 公司（智谱 / MiniMax / 商汤）→ `AI独角兽`。
   - 若 AI 只是大厂内的一个部门 / 业务线（字节豆包、腾讯混元）→ `大厂互联网`，
     但在 `match_points` 里注明「AI / 大模型方向」。
3. 多业务集团（阿里、字节）按**岗位所属事业群**判断；拿不准时标 `大厂互联网`。
4. 出海公司的中国区 AI / 运营岗，可同时体现：`company_tag` 取 `科技出海`，
   `match_points` 注明方向。
5. 不要在 `company_tag` 里塞多个标签（保持单一值，便于筛选）；多维度信息放 `tags` / `match_points`。

## 与报告的关系

- `report.py` 的 Excel / HTML 会读取 `company_tag` 渲染「公司类型」列；
  若某岗位没有该字段，该列留空，不影响其它逻辑。
- 用户可按「公司类型」在 Excel 里筛选（自动筛选已开启）。
- 检索时若用户指定「只看 AI 公司」，AI 在搜索阶段就按本规范过滤 `company_tag`。
