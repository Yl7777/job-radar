# job-radar 配置文件模板（复制为 search-config.md 后填写）

> 这是给想手动控制检索范围的人用的模板。把本文件复制成 `profile/search-config.md`
> 并按下面逐项填写，工具就能按你的个人情况工作。
> 大多数用户用 `scripts/brief.py` 问答生成即可，无需手写本文件。

---

## 一、简历（核心输入，必填）

| 项目 | 内容 |
|------|------|
| 简历文件 | 例：`/path/to/resume.pdf` 或 `resume.md`（PDF/DOCX/MD/TXT 均可） |
| 或直接粘贴文本 | 把简历全文贴在下方也可 |

> 没有简历时才进入「口述背景」模式（职业方向 / 经验年限 / 擅长技能 / 学校专业）。

---

## 二、求职类型（必填，可多选）

- [ ] 实习（日常实习 / 暑期实习）
- [ ] 校招（秋招 / 春招 / 应届）
- [ ] 社招（社招 / 社招转岗）

---

## 三、候选人画像（越具体，匹配打分越准）

| 项目 | 填你的内容 |
|------|-----------|
| 目标方向 | 例：AI 产品运营 / 后端开发(Go) / 用户增长 |
| 核心技能 | 例：Prompt 工程、SQL、内容策划、Figma（2-4 项） |
| 相关经历 | 例：某AI公司产品实习、校园公众号运营、Kaggle 竞赛 |
| 学校/专业/毕业时间 | 例：XX大学 信息管理 2027.06 毕业 |
| 经验阶段 | 在校/应届/1-3年/3-5年/5年+ |
| 每周可出勤 | 实习岗必填：例：4 天/周（很多 JD 卡"3-4 天以上"） |
| 行业偏好 | 例：AI/大模型、电商、内容社区（不填=全行业） |

---

## 四、检索平台确认（仅首次配置，之后默认全平台自动跑）

> 仅首次使用 / 尚无 `prefs.json` 时，才需运行 `scripts/brief.py` 让用户确认本次检索平台范围并生成 `prefs.json`；确认一次后，后续运行默认**全平台自动检索**，不再逐项让用户勾选。平台默认全选（含全部免登录源 + 5 个登录墙平台），用户只删不加即可。

**免登录平台（默认可选，WebSearch 直接可搜）：**

- [ ] 实习僧联盟站（rc114）
- [ ] 应届生求职网
- [ ] 牛客校招 / 牛客内推
- [ ] 海投网
- [ ] 刺猬实习
- [ ] 国聘 / 中国公共招聘网 / 教育部24365 / 各高校就业网
- [ ] 大厂官方招聘官网（字节/腾讯/阿里/美团/百度/小红书/快手…）
- [ ] 互联网中小厂官网（知乎/携程/Keep/得物/小米/大疆…）
- [ ] AI 公司官网（月之暗面/MiniMax/智谱/DeepSeek/百川/阶跃/面壁…）
- [ ] 科技出海公司官网（SHEIN/米哈游/安克/影石/蔚来…）
- [ ] 看准网（公司口碑补充）
- [ ] V2EX / 掘金社区
- [ ] 微信公众号招聘推文（弱索引，补充）

**登录墙平台（同样直接 `site:` 公开快照检索，不登录、不要求先登录；结果标「⚠️ 需手动复核」并填全再检索线索）：**

- [ ] BOSS 直聘
- [ ] 猎聘
- [ ] 智联招聘
- [ ] 前程无忧 51job
- [ ] 脉脉 / 内推

> 这些平台依赖登录态才能看完整 JD，但**公开快照可被 WebSearch 直接索引**，因此一律直接搜、不进入登录流程、不移除。详见 `references/recheck-platforms.md`。

## 五、搜索条件

| 项目 | 内容 |
|------|------|
| 目标地区 | 中国大陆（本工具仅覆盖中国大陆） |
| 目标城市 | 例：上海、杭州、深圳、北京、广州（可多选） |
| 期望薪资 | 例：实习 200-300/天；社招 25-40K·14薪（不填则不过滤） |
| 硬性要求 | 例：双休、大厂优先、外企优先（不填=照实标注不过滤） |
| 时效 | **强制**每组追加 `after:<30天前日期>`，过滤过期快照 |

**关键词组**：按 `references/platforms-cn.md` 第六节语法，为你的方向写 8-15 组，
**每组带求职类型限定词**（实习/校招/社招）。例（AI 产品运营实习）：

1. `AI产品运营 实习 城市`
2. `AI运营 实习生 城市`
3. `AIGC运营 实习 城市`
4. `大模型 产品运营 实习 城市`
5. `AI内容运营 实习 城市`
6. `AI社区运营 实习 城市`
7. `暑期实习 AI 产品 城市`
8. `日常实习 AI 运营 城市`

## 六、报告与输出

| 项目 | 说明 |
|------|------|
| Excel 表格（主交付物） | `reports/report-YYYY-MM-DD.xlsx`，每行附真实可点击链接，三档配色、冻结首行、自动筛选 |
| HTML 报告（补充） | `reports/report-YYYY-MM-DD.html`，浏览器打开即可看 |
| 去重库 | `data/jobs.db`（SQLite），跨天/跨平台去重，避免重复看到同一岗位 |
| 状态标记 | 可用 `scripts/jobstore.py mark` 标记 已投/已忽略 等，下次自动屏蔽 |
| 列结构 | 见 `references/excel-export.md` |
