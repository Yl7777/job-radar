# Excel 导出规范

> 搜索完成、去重与质检通过后，必须产出一份 Excel 表格（每个岗位附真实可点击的链接）。
> 在 job-radar 中，这份 Excel 由 `scripts/report.py` **自动生成**（与 HTML 报告同时产出），
> AI 无需自己写 openpyxl 代码；本文件定义表格的列结构与格式，供 `report.py` 与人工核对使用。

使用 openpyxl 生成 `.xlsx` 文件（如手动生成，需先确认用户已安装 `pip3 install openpyxl`），包含以下列：

| 列名 | 说明 |
|------|------|
| 编号 | 序号 |
| 变化 | 本期变化类型：🆕 新增 / 🔄 更新 / ♻️ 重开 / ⚠️ 疑似下架（来自 `new_jobs.json` 的 `_event` 字段） |
| 匹配度 | 🟢高度匹配 / 🟡基本匹配 / 🟠可以尝试 |
| 岗位名称 | 职位标题 |
| 公司 | 公司名称 |
| 公司类型 | `company_tag`：大厂互联网 / AI独角兽 / 科技出海 / 创业公司 / 国企央企 / 外企 / 其他（见 `company-classification.md`） |
| 城市 | 工作地点 |
| 薪资 | 薪资范围 |
| 经验要求 | 年限要求 |
| 发布日期 | 摘要/页面中的发布时间（如「3天前」「2026-06-01」）；登录墙平台确认不了的填「⏳未确认」；该字段同时也是「再检索线索」之一 |
| 匹配点 | 简历中匹配的技能/经历 |
| 标签 | 双休/外企/大厂/远程 等 |
| 来源平台 | Boss直聘/猎聘/牛客/官网 等 |
| 链接 | 岗位详情 URL（**必须真实可点击**，质检已验证） |
| 备注 | 额外信息（如"急招"、"同名不同岗"等）；登录墙平台岗位会自动追加「【需手动复核】再检索线索：岗位名｜帖子标题｜作者｜发送时间｜来源」 |

**登录墙平台（需手动复核）字段约定**：BOSS/猎聘/智联/51job/脉脉 等登录墙平台搜到的岗位，固定 `needs_recheck = true`，并尽量填全以下字段作为「再检索线索」——报告会在 HTML 卡片与 Excel 备注列展示，供用户在对应 App 内自行确认在招与投递：
- `needs_recheck`：布尔，固定 `true`
- `post_title`：帖子 / 内推帖标题（来源是帖子而非官招页时填）
- `author`：作者 / 发帖人 / HR 昵称
- `posted`：发送 / 发布时间（即上表「发布日期」列）
- `title` / `source`：上表已有，必填

详见 `references/recheck-platforms.md`。

**Excel 格式要求：**
- 表头行：加粗白色字体 + 蓝色背景（`#4472C4`）+ 居中
- 🟢 行：浅绿底色（`#E8F5E9`）
- 🟡 行：浅黄底色（`#FFF8E1`）
- 🟠 行：浅橙底色（`#FFF3E0`）
- ⚠️ 疑似下架 行：浅红底色（`#FFC7CE`）
- 链接列：蓝色下划线字体（可点击跳转）
- 冻结首行 + 启用自动筛选器
- 文件名：`report-YYYY-MM-DD.xlsx`（在 `reports/` 目录，与 HTML 报告同名）

**变化事件说明（只推变化，不复发全量）：**
- 每次运行 `jobstore.py filter` 会把本轮检索结果与历史库对比，只把"发生变化"的岗位写入 `new_jobs.json`：
  - `new`：从未见过的链接；
  - `updated`：同一链接，JD / 薪资 / 要求等核心内容变了（`content_hash` 变化）；
  - `reopened`：之前疑似下架，本次重新出现；
  - `possibly_closed`：连续 3 次「完整检索却搜不到」→ 疑似下架（一次没搜到不误判）。
- 报告据此分区：新增 / 更新 / 重开 按匹配度分组展示；疑似下架单独列在警告区。

**追加模式：**

如果已有 Excel 文件（如用户要求"把 BOSS 直聘分组的也加进去"），使用 `load_workbook` 追加：

```python
from openpyxl import load_workbook
wb = load_workbook("已有文件.xlsx")
ws = wb.active
# 编号从 ws.max_row 开始递增
# append 新行后，逐行设置填充色和字体
# 更新 auto_filter.ref 的范围
wb.save("已有文件.xlsx")
```

追加时注意：
- 编号接续已有最大编号
- 去重：检查「岗位名称 + 公司名 + 链接」是否已存在，避免重复添加
- 来源平台标注区分（如 "Boss直聘·分组" vs "Boss直聘" vs "猎聘"）

> 注：job-radar 仅覆盖中国大陆岗位，故**不设置「签证/工签」列**（job-hunt 海外岗位专用）。
> 若后续接入海外岗位，再按 job-hunt 的签证列规则补回。
