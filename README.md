# 📡 岗位雷达 job-radar

> 你的中国大陆求职雷达 —— 把简历交给 AI，它帮你把合适的岗位整理好送到面前。

**适合谁**：正在找实习 / 校招 / 社招的人，方向不限（产品、开发、算法、运营、设计……）。

---

## 我们的优势

- **全平台一起搜**：不只搜一两个常用 App，而是把实习网站、大厂官方招聘页、综合招聘平台、内容社区一起覆盖，尽量避免漏掉好岗位。
- **不重复、不刷屏**：自动去重，你每天看到的都是真正新出现的岗位，而不是反复出现的老面孔。
- **操作简单**：你只需要把简历交给 AI，剩下的检索、整理、去重都交给它完成。
- **可每天自动推**：设置一次定时任务，每天早上就有新的岗位推荐，省去天天手动搜。

---

## 它能做什么

- 🌐 **覆盖多家平台**：实习类网站、大厂官网、综合招聘平台、技术 / 求职社区。
- 📄 **读懂你的简历**：上传简历或简单描述背景，AI 据此找到更匹配的岗位。
- 🚧 **提示疑似失效岗位**：会检查链接是否还能打开，明显已下架的会特别标注，最终是否仍在招请在 App 内确认。
- 🔁 **自动去重**：同一岗位不会反复出现，每天只推新变化。
- 🟢🟡🟠 **清晰分级**：高度匹配 / 基本匹配 / 可以尝试，一目了然。

## 如何安装

如果你使用的是支持 skill 的 AI 工具（例如 WorkBuddy、Codex 等），只需对 AI 说一句话：

> **请你帮我安装这个 skill: https://github.com/Yl7777/job-radar**

AI 会自动帮你装好，无需任何命令行操作。

---

## 如何使用

把你的简历交给 AI，说：

> **这是我的简历，请你利用 job-radar skill 给我进行岗位推荐**

AI 会先和你确认几个关键信息（求职类型、方向、城市、希望覆盖的平台等），
然后开始检索，最后给你一份整理好的岗位清单，每条都带可点击的链接和匹配说明。

---

## 设置定时自动推荐

如果 job-radar 已经安装在 WorkBuddy 或 Codex 中，你还可以直接对 AI 说：

> **请你帮我设置一个定时任务，每天早上 8 点利用 job-radar skill 帮我执行一次新增岗位推荐**

设置好之后，无需每天手动操作，AI 会按时帮你检索并把新岗位整理出来。

---

## 关于需要登录的平台（BOSS / 猎聘 / 智联 / 51job / 脉脉）

这些平台通常需要登录才能看完整内容，但**它们对外公开的招聘信息仍然能被搜到**。

job-radar 会把这些平台的公开信息一并检索进来，并在结果里标注「需手动复核」，
附上岗位名、来源等线索。你拿到线索后，在自己已登录的 App 里确认是否还在招、再投递即可。

> ⚠️ 这类平台的结果 AI 无法 100% 确认是否仍在招，投递前请在对应 App 内自行确认。
